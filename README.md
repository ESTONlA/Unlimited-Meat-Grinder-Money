# Unlimited Meat Grinder Money

A simple MelonLoader mod that makes the **Meat Grinder** give you massive amounts of money every time you clean it.

## Features

- Forces `minMoneyReward` to **999,999**
- Forces `maxMoneyReward` to **9,999,999**
- Reduces the grinder `Delay` to **0.1** seconds so you can use it much faster
- Works automatically  no config needed

## Requirements

- [MelonLoader](https://melonwiki.xyz/) (latest version recommended)
- The game must be MelonLoader-compatible

## Installation

1. Install MelonLoader if you haven't already
2. Download the latest release of this mod
3. Place the `.dll` file into your game's `Mods` folder
4. Launch the game

## Usage

Just clean the Meat Grinder like normal.  
You will now receive an extremely high amount of money every time.

## Building from Source

1. Create a new MelonLoader mod project
2. Reference the game's `Assembly-CSharp.dll`
3. Paste the source code
4. Build the project
5. Copy the output `.dll` to the `Mods` folder
